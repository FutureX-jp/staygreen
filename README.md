# StayGreen

作業中なのに、Teams などの在席表示が勝手に「退席中（オレンジ）」へ変わるのを防ぐ Windows 用の常駐ツールです。
会議・図面の確認・資料を読んでいる間など、キーボードやマウスに触らない時間が続いても「連絡可能（緑）」のままにします。

- 無料・インストール不要（exe 1つ・約300KB）
- インターネットに出るのは「新しい版が出ていないかの確認」（GitHub を読むだけ・メニューで切れます）と、「送ってもよい」と答えた場合の不具合の記録だけです。Teams の中身・アカウント名・履歴は、どこにも送りません
- 決めた時間帯だけ動きます（最初の設定は 月〜金の 08:00〜12:00 と 13:00〜17:30。昼休みと土日は自動で止まります）

## ダウンロード

[Releases](https://github.com/FutureX-jp/staygreen/releases/latest) から `StayGreen_x.y.z.zip` を落として、解凍した `StayGreen.exe` をダブルクリックするだけです。

初回に「Windows によって PC が保護されました」と出たら、[詳細情報] →[実行] を押してください（発行元の署名を付けていない個人作成のソフトのため表示されます）。

## できること

- 決めた間隔（最初は60秒）で、何も起きないキー（F15）と、1ドットだけ動かして戻すマウス操作を Windows に送ります。文字が入力されたり、カーソルが動いて見えたりはしません
- 曜日ごとに時間帯を3つまで決められます。時間帯の外は自動で止まり、時間になると自動で始まります
- 「見張り」の欄に、いまの Teams の在席表示（会社のアカウント／個人のアカウント）を出します。このパソコンの中にある Teams の記録を読むだけで、Teams のサーバーやアカウントには触れません
- 窓の × を押しても終了せず、通知領域（画面の端の小さいアイコンの並び）に入って動き続けます。右クリックで 開始・停止／再起動／終了、パソコンの起動・再起動のたびに自動で始める設定ができます
- 新しい版が出ると、同じメニューに [新しい版 ○○ に更新する] が出ます。押して「はい」と答えた時だけ、落として入れ替え、自動で起動し直します
- 動いた履歴を日付ごとの CSV に、不具合の記録を `logs\エラー.log` に残します（どちらも exe と同じフォルダの中）

## インターネットへの通信について

- 起動した時と6時間ごとに、新しい版が出ていないかをこのページ（GitHub）へ見に行きます。読むだけで、こちらからは何も送りません（通信なので、接続元の IP アドレスは GitHub 側に伝わります）
- やめるには、通知領域のメニューの [新しい版を自動で確認する] のチェックを外してください
- 更新は勝手には始まりません。落とした物が案内と1バイトでも違えば入れ替えず、入れ替えた後に起動を確かめられなければ元の版に戻します。前の版は `StayGreen.exe.bak` として残ります
- 不具合の記録を作者へ送るのは、「送ってもよいですか？」に「はい」と答えた時だけです（最初は送りません。聞くのは1回だけで、「いいえ」でも今までどおり使えます）
  - 送る物: 何が起きたか（エラーの種類と短い文）・StayGreen の版・Windows の版・でたらめな番号
  - 送らない物: 名前・メールアドレス・Teams の中身・フォルダやファイルの場所（消してから送ります）
  - 送り先: 作者の Google スプレッドシート（Google Apps Script で受け取ります）
  - あとでやめる時は、通知領域のメニューの [不具合の記録を作者に送る] のチェックを外してください
- 2.4.1 までは通信を一切しない作りでした。2.4.1 をお使いの方は、一度だけ手で入れ替えてください（`StayGreen.exe` を上書き。設定と履歴は残ります）

## 効かない場面

- 画面をロックしている間（Windows の仕様で、ロック中は操作を受け付けません）
- リモートデスクトップを切断している間（最小化なら効きます）
- Teams の在席表示を自分で「退席中」などに固定している時

## 使う前に

- このソフトは「パソコンに操作があった」と Windows に伝えるだけで、Teams のサーバーやアカウントには触れません
- 実際には席にいないのに在席しているように見せる使い方は、勤務先のルールに反することがあります。席にいて作業しているのに退席中になってしまう、という困りごとを防ぐ範囲で、勤務先のルールを確認のうえ使ってください
- 無料で使えますが、動作の保証はありません。使ったことで起きた結果について、作者は責任を負いません

## 動作環境

Windows 11 で確認しています（Windows 10 でも動く作りですが、確認はしていません）。追加のインストールは不要です。
